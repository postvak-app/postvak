# Sending mail, part 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Send new mail, replies (to the sender or all) and forwards from the CLI over SMTP, through an outbox in the daemon with an undo delay, with a Sent copy and SMTP settings guessed for new and existing accounts.

**Architecture:** A new `send` module in `postvak-core` holds everything pure (settings guess, building, checking, reply/forward, the HTML quote, sendmail arguments, outbox files) and the SMTP client behind a `SmtpOps` trait. The daemon owns one sender thread per account beside the engine's IMAP threads; the sender hands the Sent copy and the flag on the original to the IMAP thread as a `sync::Command`. Front ends talk to it through new wire messages on `daemon::Client`.

**Tech Stack:** Rust, `lettre` (SMTP + message builder, rustls/ring, tokio), `html5ever` (HTML quote), `mail-parser`, `psl`, rusqlite migrations, clap.

**Spec:** `docs/superpowers/specs/2026-11-02-sending-design.md`

## Global Constraints

- Definition of done from `AGENTS.md`: `cargo fmt --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test`, `cargo machete`, `cargo deny check` pass; no `unwrap`/`expect`/`panic!` outside tests.
- New dependencies get a one-line reason in root `[workspace.dependencies]`; crates use `workspace = true`. `lettre` with `default-features = false` and features `builder`, `smtp-transport`, `tokio1`, `tokio1-rustls`, `ring`, `rustls-native-certs` off (use `webpki-roots` like IMAP; follow lettre's feature names for its version).
- `postvak-core` must not pull in Slint, Blitz or rmcp (`tests/architecture.rs`). `html5ever` is allowed.
- `config` is the only writer of config.toml (`save_account`); the daemon never writes config.toml.
- Never log recipients, subjects or bodies; log the outbox id and account only.
- A guess never logs in without TLS and only to a host with the IMAP host's registrable domain.
- Undo delay values: 0, 5, 10 (default), 20, 30 seconds. Size limit without `SIZE`: 25 MB (`25 * 1024 * 1024`). Temporary-failure retries stop after one hour.
- Restart: a message in state `sending` is never sent again; it becomes `failed` with reason `may have been sent; check Sent before retrying`.
- Prefixes (case-insensitive) that stop another `Re: `: `Re:`, `Aw:`, `SV:`, `Antw:`, `Fwd:`, `Fw:`, `WG:`, `TR:`, `Doorst:`; that stop another `Fwd: `: `Fwd:`, `Fw:`, `WG:`, `TR:`, `Doorst:`.
- Plain text is `format=flowed`, the user's lines wrapped at 72; quoted lines are not rewrapped.
- `--raw` skips the undo delay, waits for the server, exits 0 / 75 / 69, and saves no Sent copy unless `--save-sent`.
- HTML quote wrapper: `<div class="gmail_quote"><blockquote type="cite" class="gmail_quote" style="margin:0 0 0 .8ex;border-left:1px solid #ccc;padding-left:1ex">…</blockquote></div>`.
- Sent copy skipped by default for SMTP hosts `smtp.gmail.com`, `*.google.com`, `smtp-mail.outlook.com`, `smtp.office365.com`.
- Part 1 ships on the CLI, with the outbox counts in the GUI status bar; no MCP tool.
- After CLI changes: `POSTVAK_BLESS=1 cargo test`; after GUI changes: `TZ=UTC UPDATE_SNAPSHOTS=1 cargo test -p postvak-gui snapshots` and look at the PNGs.

## Review Focus

1. **A wildcard alias as From** (`*@example.com`): `--from shop@example.com` is accepted, `--from '*@example.com'` refused — test in Task 5.
2. **Reply-all to a message that went to an alias and the account address both**: neither of ours appears in To/Cc — test in Task 7.
3. **HTML original with a `<base href>` and `<img onerror>`**: both removed, `cid:` images still resolve — test in Task 8.
4. **Daemon killed between `sending` and `sent`**: restart marks it failed, nothing resent — test in Task 11.
5. **git send-email invocation** `postvak send --raw -i -f me@example.com -- a@x.org bcc@y.org` with Bcc absent from headers: both get the message, From check passes — test in Task 9.
6. **Reply to a message in Sent**: goes to the original To, not to ourselves — test in Task 7.
